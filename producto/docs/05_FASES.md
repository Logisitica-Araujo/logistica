# 05 · Fases de trabajo

Cada fase termina con una **vista previa** que se aprueba antes de pasar a la siguiente.

## Fase 1 · Diseño y documentos ✅ (este paquete)
- [x] Arquitectura núcleo / módulos / excepciones
- [x] Inventario de la app actual
- [x] Diseño de seguridad
- [x] Diseño de configuración
- [x] Borradores legales (aviso de privacidad, términos, políticas, contrato y anexos)
- [x] Vista previa del asistente de configuración
- [ ] **Aprobación** del diseño y del nombre comercial

## Fase 2 · Extracción y limpieza
- [ ] Copiar el código a `producto/app/` sin datos ni IDs de FADERMEX
- [ ] Renombrar a vocabulario universal (traslado, ubicación, pieza, portador)
- [ ] Estados universales (8)
- [ ] Quitar Botican, Operaciones y reglas de Morelia; dejarlos como ejemplo en `Cliente_Ejemplo.gs`
- [ ] Pruebas automáticas del núcleo pasando

## Fase 3 · Configuración y módulos
- [ ] Hojas `CFG_*` y lectura de módulos activos
- [ ] Asistente de configuración funcional
- [ ] Importar ubicaciones / personas desde Excel
- [ ] Módulos: resguardo, envío externo, consolidados, piezas parciales, alertas
- [ ] Enchufes para excepciones

## Fase 4 · Seguridad
- [ ] Hash de credenciales y NIP + migración
- [ ] Bitácora encadenada + verificación
- [ ] Roles Supervisor y Soporte, sesiones con vencimiento y cierre remoto
- [ ] Respaldo semanal, retención, exportación completa

## Fase 5 · Reportes y evidencia
- [ ] Tablero básico (núcleo) y avanzado (módulo)
- [ ] Evidencia con foto / firma (módulo)

## Fase 6 · Material de venta
- [ ] Empresa demo "Grupo Ejemplo" con datos ficticios
- [ ] Manuales genéricos (administrador, ubicación, resguardo, portador)
- [ ] Guiones de videos (1 min presentación, 3 min demo, tutoriales cortos)
- [ ] Página de presentación (landing) con precios y formulario de contacto

## Fase 7 · Legal y empresa (tú + abogado)
- [ ] Registro de marca (IMPI) y de software (INDAUTOR)
- [ ] Revisión de los borradores legales por abogado
- [ ] Alta fiscal para facturar (RFC, CFDI)

## Fase 8 · Pilotos y lanzamiento
- [ ] 2–3 pilotos con acuerdo de piloto
- [ ] Ajustes con lo aprendido, precios finales
- [ ] Campaña: LinkedIn, video, Google Workspace Marketplace, directorios de software
